# Student Management System

## Project Overview
The Student Management System is a CLI-based Python application used to manage student records efficiently. The system allows users to add, view, update, and delete student details while storing data permanently in a JSON file.

## Features
- Add Student Records
- View Student Records
- Update Student Information
- Delete Student Records
- Store Data Using JSON
- Menu-Driven Interface
  
## Technologies Used
- Python 3
- JSON File Handling
- Command Line Interface (CLI)
  
## Concepts Used
- Functions
- Lists
- Dictionaries
- CRUD Operations
- File Handling
- Loops and Conditions
